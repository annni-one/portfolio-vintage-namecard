✨ 项目名称：愿者上钩 雾境名片
🎨 风格：黑金复古档案质感，翻页式人设名片网页
🎯 用途：个人作品集展示，全部源码开放，可复制参考复用
🛠️ 技术：HTML + CSS 静态单页网站
🔗 在线预览：https://yuanzheshang.pages.dev

📌 项目说明：
独立完成视觉设计与前端开发。页面采用复古档案排版，搭配翻页交互，适合作为线上个人名片。
源码完整开放，大家可以直接复制学习，二次修改。

---

## ✨ 模板特点
- **复古黑金视觉**：深色背景搭配金色细节，带有旧报纸、档案卡、私藏手册般的质感
- **情绪化文案表达**：不只是展示作品，也可以展示个人气质、态度与创作风格
- **卡片式信息结构**：个人介绍、标签、案例、作品图片与联系方式分区清晰，方便浏览
- **轻量化页面**：以 HTML + CSS 为核心，结构简洁，加载速度快，无需复杂框架
- **移动端友好**：适合在手机端浏览，也适合作为社交平台引流后的落地页
- **可直接复用**：替换文字、图片和案例内容后，即可作为个人作品集或接单主页使用

## 📦 使用方法
1. 下载项目源码并解压
2. 使用 VS Code、记事本或其他代码编辑器打开 `index.html`
3. 替换模板中的姓名、标题、简介、标签、案例图片和联系方式
4. 将自己的图片、音频等资源放入 `assets` 文件夹
5. 保存后双击 `index.html`，即可在浏览器中本地预览
6. 上传到 GitHub 或其他托管平台后，可部署为在线个人作品集网站
